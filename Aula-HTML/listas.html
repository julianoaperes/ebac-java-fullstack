Listas Ordenadas

As listas ordenadas em HTML organizam itens em uma sequência identificada por números ou letras. São úteis quando a ordem importa, como em instruções, etapas de cadastro, rankings e receitas.

A tag "< ol >" significa Ordered List e delimita a lista ordenada. A tag "< li >" significa List Item e representa cada item da lista.

Exemplo

  1. Primeiro item
  2. Segundo item
  3. Terceiro item

Atributo "type": formato dos marcadores

  • O atributo type define o tipo de numeração. Números decimais — padrão: 1,2,3...
  • Letras maiúsculas: A,B,C...
  • Letras minúsculas: a,b,c...
  • Algarismos romanos maiúsculos: I,II,III ...
  • Algarismos romanos minúsculos: i, ii, iii ...

Exemplo

  1. Introdução
  2. Desenvolvimento
  3. Conclusão

Atributo start: número inicial

Por padrão, a lista começa em 1. O atributo start permite escolher outro número inteiro.

Exemplo

  1. Revisar os dados
  2. Enviar o formulário
  3. Aguardar a confirmação

Mesmo quando o formato usa letras ou algarismos romanos, o valor de start deve ser um número inteiro:

Exemplo

  1. Terceira opção
  2. Quarta opção

Atributo reversed: ordem decrescente

Reversed é um atributo booleano: sua presença ativa o comportamento. Portanto, reversed="false" também ativa a contagem decrescente. Para desativá-la, remova o atributo.

Exemplo

  1. Terceiro lugar
  2. Segundo lugar
  3. Primeiro lugar

Atributo value: alterar a numeração de um item

O atributo value pertence ao "< li >" e permite definir o número daquele item. Os próximos continuam a contagem a partir dele.

Listas NÃO Ordenadas

As listas não ordenadas em HTML agrupam itens cuja sequência não é importante. Elas usam marcadores, geralmente bolinhas, em vez de números ou letras. São úteis para listas de compras, características de produtos, menus e conjuntos de opções.

Estrutura: "< ul >" e "< li >"". A tag "< ul >"" (Unordered List) delimita a lista, enquanto "< li >" (List Item) representa cada item.

Exemplo

  • Primeiro item
  • Segundo item
  • Terceiro item
