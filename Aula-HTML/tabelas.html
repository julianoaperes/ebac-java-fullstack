Tabelas

As tabelas em HTML organizam dados em linhas e colunas, permitindo relacionar e comparar informações. São úteis para apresentar notas, preços, resultados de testes e cadastros.

Tags

  • "< table >":Define a tabela
  • "< caption >":Define o título ou a descrição da tabela
  • "< tr >":Define uma linha
  • "< th >":Define uma célula de cabeçalho
  • "< td >":Define uma célula de dados
  • "< thead >":Agrupa as linhas de cabeçalho
  • "< tbody >":Agrupa as linhas de dados
  • "< tfoot >":Agrupa as linhas de rodapé, como totais

Cabeçalho

A tag "< th >" identifica um cabeçalho, que pode descrever uma coluna ou uma linha.O atributo scope informa a quais células o cabeçalho se refere:
  • scope="col": cabeçalho de uma coluna.
  • scope="row": cabeçalho de uma linha.

Título "< caption >"
