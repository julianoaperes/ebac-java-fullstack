Formulários

Os formulários em HTML permitem coletar informações do usuário, como nome, e-mail, senha e opções de preferência. São usados em cadastros, login, pesquisas, buscas e envio de mensagens. O HTML define os campos e algumas regras de validação. O processamento dos dados, como salvar um cadastro ou verificar uma senha, normalmente acontece no back-end.

Tag "< form >"": estrutura do formulário

Esta tag agrupa os campos e define como os dados serão enviados.
